## Como reutilizarlo

Para esto es muy sencillo solo tienes que descargar el repositorio, una vez hecho esto. Tienes que ir a la carpeta de Services que es donde están los datos y modificarlos a tu gusto.
También hay otros servicios los cuales se meten que son de proyectos personalizados los cuales tendrás que modificar también en otros aspectos

Para arrancar el servidor tienes que escribir esto en la terminal
```csharp
dotnet run
```
